# 우리사이 연구소 · Woorisai Lab

두 사람이 각자 12문항에 답하고 서로의 선택을 비교하는 모바일 웹 MVP입니다. 전체 답변 비교와 시작 질문은 무료이며, 선택형 대화 가이드는 주제 5개·질문 10개·대화 예시·합의 양식으로 구성됩니다.

**현재 로컬 검증용입니다. 실제 결제·고객 검증·상용 정책 검토·운영 배포는 완료되지 않았습니다.** 모의 구매는 실제 매출이나 수요 검증으로 집계하지 않습니다.

## 실행 환경

- Node.js 22 이상, pnpm 10.31.0
- 기존 Docker PostgreSQL 17, 호스트 포트 **1992**
- 웹 `http://127.0.0.1:3200`, API `http://127.0.0.1:4000`
- E2E는 웹 3100·API 4100·전용 테스트 DB 사용. 테스트 브라우저는 Google Chrome입니다.

이 환경에서는 `psql_ptk_17` 컨테이너에 `woorisai_lab`와 `woorisai_lab_test` DB를 생성해두었습니다. 기존 DB나 컨테이너를 교체하지 않았습니다. 새 환경에서는 해당 두 DB를 먼저 만들고 접속 정보를 설정하세요.

## 빠른 시작

```sh
pnpm install
# 새 checkout에서만: cp .env.example .env
# .env의 DATABASE_URL / TEST_DATABASE_URL / 임의의 토큰 해시 키를 실제 로컬 값으로 설정
pnpm db:migrate
pnpm db:seed
pnpm dev
```

현재 checkout의 `.env`는 설정되어 있으며 Git에서 제외됩니다. 기존 `.env`를 예제 파일로 덮어쓰지 마세요. 토큰 키는 최소 32자 무작위 값이 필요합니다. 웹과 API는 루프백에만 바인딩합니다.

`pnpm db:seed`는 재실행할 수 있으며 기존 버전의 문항을 덮어쓰지 않습니다. 스키마 자동 동기화는 사용하지 않습니다.

## 구현된 흐름

1. `/start`에서 성인 대상·답변 공개 범위에 동의하고 별명 입력.
2. 각 문항 저장, 새로고침 복구, 제출 전 수정·확인.
3. 본인 결과와 초대 링크. 초대 페이지 GET은 상대 슬롯을 차지하지 않음.
4. 상대의 명시적 참가 후 별도 쿠키로 설문 응답.
5. 두 사람 제출 후 전체 12문항 비교와 무료 질문 2개.
6. 3,900원 **모의 결제**: 성공/실패/보류/취소/환불.
7. 서버 확인 후 A/B 공동 대화 가이드·인쇄형 PDF.
8. 선택형 사용 피드백, 두 사람의 응답·결과 삭제.

답변이 비슷하거나 모두 중립이어도 존재하지 않는 차이를 만들지 않습니다. 네 주제는 심리척도가 아닌 분류이며, 평균·궁합 점수·유형·미래 예측을 제공하지 않습니다. 실제 대화·합의 내용은 서버에 저장하지 않습니다.

## 검증 명령

```sh
pnpm typecheck
pnpm test
pnpm test:integration
pnpm test:e2e
pnpm build
```

통합 테스트는 `TEST_DATABASE_URL`의 DB 이름이 `_test`로 끝날 때만 실행하며, 그 DB의 세션 데이터를 초기화합니다. **운영 DB를 테스트 URL로 설정하지 마세요.** E2E도 동일 전용 테스트 DB만 사용하고 API/웹 서버를 자체 실행·종료합니다. 통합 테스트와 E2E는 순서대로 실행하세요.

E2E는 Google Chrome이 설치된 환경을 기준으로 합니다. 다른 CI 환경에서는 `playwright.config.ts`의 채널을 바꾸고 해당 브라우저를 준비하세요. 실패 시 trace·스크린샷은 Git에서 제외된 `test-results/`에 저장됩니다.

빌드는 Next.js 최적화 결과와 NestJS 번들을 생성합니다. API 번들 자체는 `pnpm --filter @woorisai/api start`로 실행할 수 있습니다. **`NODE_ENV=production`에서 mock 결제를 사용하면 API는 부팅을 거부합니다.** 이는 실결제 없는 상태의 상용 배포를 방지하기 위한 의도된 동작입니다.

## 구조

```text
apps/web/                 Next.js 화면·동일 사이트 API 프록시·인쇄 CSS
apps/api/src/             NestJS HTTP 서버·권한·트랜잭션·결제·결과
apps/api/src/domain/      서버 전용 비교 엔진·대화 콘텐츠·결제 어댑터
apps/api/src/db/          TypeORM migrations·seed·만료 데이터 정리
packages/shared/         공개 문항·선택 레이블·Zod 스키마·DTO
apps/api/test/            도메인 단위·PostgreSQL HTTP 통합 테스트
tests/e2e/               독립 A/B 브라우저 모바일 시나리오
scripts/metrics.sql      집계 지표 SQL
docs/                    기획·샘플·ADR·검증 양식·구현 상태
```

유료 생성 템플릿은 서버 전용이며 공유 패키지·클라이언트 번들에 포함하지 않습니다. 공개 샘플 API에는 가상 데이터로 만든 결과만 나갑니다. 실제 무료 결과 API는 유료 카드·예시·합의 양식을 보내지 않습니다.

## 보안과 데이터 관리

- 참여자별 HttpOnly/SameSite 쿠키, 원문 토큰 대신 HMAC 해시 저장.
- 상태 변경은 Origin과 커스텀 요청 헤더 검증. 웹은 동일 사이트 rewrite 사용.
- session 행 잠금·고유 제약으로 B 슬롯, 결과 생성, 활성 주문·권한 중복 방지.
- 결제는 별도 mock ledger를 검증. 클라이언트가 보낸 금액·성공 상태로 권한 부여 금지.
- 모의 웹훅은 HMAC 서명·5분 시간창 검증, 공급사 거래 상태 재조회·멱등 처리.
- URL·답변·닉네임·토큰·민감 PG 정보는 로그와 분석 속성에서 제외.
- 개인 결과 HTTP는 캐시하지 않음. 초대 페이지는 외부 리퍼러를 전송하지 않음.
- 개발 기준 미완료 14일·완료 90일 이후 접근 차단. `pnpm db:purge`로 만료 개인 내용 삭제. 배포 시 정기 실행과 모니터링을 설정해야 하며 현재 자동 운영 스케줄은 없음.
- 수동 삭제는 두 사람의 응답·결과·피드백·접근 토큰을 제거하고 유료 권한을 철회함. 거래 기록은 개인 답변과 분리해 유지. 운영 보존 규칙은 실서비스 전에 확정.
- 공개 페이지의 선택형 통계는 `/privacy`에서 동의 후만 수집. 필수 참여·거래 이벤트와 피드백 분모를 구분. 동의한 공개 방문자만 측정되므로 전체 방문 전환율로 일반화하지 않음.

- 목표 고객의 실제 Phase 0 관찰과 무료 참여·대화 가치 검증.

- 실제 운영 환경·분산 속도 제한·HTTPS/HSTS·백업·복구·정기 삭제·장애 알림 설정.
