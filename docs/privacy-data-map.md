# 개발 MVP 데이터 흐름

| 정보 | 저장 위치 | 누구에게 보이는가 | 삭제 |
|---|---|---|---|
| 별명 | participants | 본인, 공동 완료 후 상대 | 세션 삭제/만료 정리 |
| 문항 응답 | survey_answers, 확정 snapshot | 본인, 공동 완료 후 상대 | 세션 삭제/만료 정리 |
| 접근 토큰 | 브라우저 HttpOnly 쿠키, 서버 HMAC 해시 | 각 참여자 브라우저만 | 참여자 삭제로 서버 접근 무효 |
| 초대 토큰 | 초대 URL·A의 sessionStorage, 서버 HMAC 해시 | 링크를 전달받은 사람 | 회전/만료/삭제로 서버 무효 |
| 결과·대화 가이드 | result_snapshots | 본인과 상대, premium은 구매 권한 필요 | 세션 삭제/만료 정리 |
| 선택형 피드백 | session_feedback | 운영 집계, 상대에게 비노출 | 세션 삭제/만료 정리 |
| 모의 거래 | orders/payment_events/mock_gateway_transactions | 해당 참여자 주문 조회, 운영 감사 | 개인 연결 제거 후 별도 보관 |
| 필수 참여 이벤트 | analytics_events | 운영 집계 | 세션 삭제/만료, 공개 이벤트 90일 정리 |
| 선택형 페이지 통계 | consent 후 analytics_events | 운영 집계 | 세션/보존 정책, 익명 식별은 sessionStorage |
| 실제 대화·작성된 약속 | 서버 저장 없음 | 종이·개인 기기 | 이용자 관리 |

개인정보를 제3자 AI·분석 도구로 보내지 않는다. Next 요청 URL 로그를 끄고, API는 requestId/일반 오류 코드만 기록한다. 닉네임·답변·토큰을 로그/분석 속성으로 받지 않는다. 외부 리소스 요청을 사용하지 않으며 no-referrer와 동일 사이트 API를 사용한다.

현재 미완료 14일·완료 90일은 개발 기준이다. 시간 경과 후 API 접근은 즉시 차단되며 실제 데이터 제거는 `pnpm db:purge` 실행이 필요하다. 운영 스케줄·보관 기간·고객지원·법적 정책은 미확정이며 공개 운영 전 준비해야 한다.
