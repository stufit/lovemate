# Phase 0 — 실제 고객 관찰 양식

상태: **진행 자료 준비 완료 · 실제 관찰 미실행**. 가상 샘플·자동화 테스트 통과는 실제 고객 검증 통과를 뜻하지 않는다.

## 모집 조건

20~30대 성인 연인, 평소 큰 문제는 없지만 서로의 선호를 더 이해하고 싶은 커플. 첫 5쌍 중 응답 차이가 적은 커플을 포함하고 필요시 최대 10쌍까지 관찰한다. 연락·모집은 별도 실행하며 자발적 참여와 답변 공개 범위를 설명한다.

## 관찰 순서

1. 기본 결과 무료·가이드 선택 가격 3,900원, 두 사람 완료 후 답변 공개 안내.
2. 각자 12문항 응답. 문항/가운데 선택을 이해하지 못한 곳 기록.
3. 상대 초대부터 공동 완료까지 어디서 막혔는지 관찰.
4. 추가 설명 없이 무료 결과를 읽게 하고, 무엇을 뜻하는지 자신의 말로 설명하게 한다.
5. 편한 질문 하나를 골라 실제로 대화해보게 한다. 원치 않으면 건너뛰어도 된다.
6. 가이드의 예시·질문·약속 양식 중 무엇이 유용했는지 구체적인 사용 맥락만 확인한다.
7. 가격을 보고 구매할/하지 않을 이유를 묻는다. 무료 제공·구매 의향·모의 구매를 실제 구매와 분리한다.

## 익명 집계

| 구분 | 결과 |
|---|---|
| 관찰일 / 모집 채널 / 모집 시간 | 미기록 |
| 참여·공동 완료 커플 수 | 미기록 |
| 설명 없이 응답과 결과 관계를 이해한 커플 수 | 미기록 |
| 실제 대화에 사용한 커플 수 | 미기록 |
| 구체적 유용성을 설명한 커플 수 | 미기록 |
| 차이 적은 커플에서의 사용 사례 | 미기록 |
| 불편·편향·중복·이해 어려움 | 미기록 |
| 실제 결제 / 의향 / 모의 구매 구분 | 미기록 |
| 수정 내용과 재관찰 계획 | 미기록 |
| 진행 / 보류 판단과 근거 | 미기록 |

실명·연락처·원문 답변·대화 내용을 Git에 기록하지 않는다. 내부 탐색 기준은 첫 5쌍 중 4쌍 이상 이해, 3쌍 이상 실제 대화와 구체적 유용성 확인이다. 표본이 작으므로 통계적 확증이나 효과 보장으로 해석하지 않는다.


## 바로 진행하는 자료

- [참가자 안내](participant-guide.md): 참여 전 안내와 공개 범위.
- [진행자 절차](moderator-guide.md): 접속 분리, 과제, 관찰·인터뷰 순서.
- [기록·집계 사용법](recording-guide.md): 5쌍의 실제 관찰 결과를 익명으로 기록.
- [초기 양식](records.example.json): 모든 판정은 미관찰(null) 상태.

`pnpm validation:init`으로 로컬 전용 기록을 만들고, 실제 관찰 후 `pnpm validation:report`로 집계한다. 결과는 Git에 저장하지 않는다. 이 문서의 실제 관찰 수는 직접 갱신하지 않으며, 최신 수치는 로컬 관찰 기록의 집계로 확인한다.

진행 방식은 **2026-11-23 사용자 선택에 따라 같은 자리에서 직접 테스트**로 확정했다. 첫 진행은 [대면 테스트 체크리스트](on-site-checklist.md)를 따른다. 웹 3200과 API 4000의 정상 응답을 확인했다. 원격 테스트 배포는 진행하지 않는다.
