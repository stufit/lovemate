# 대면 테스트 — 첫 커플 진행 체크리스트

진행 방식: 2026-11-23 사용자 선택으로 확정. 이 체크리스트는 진행 자료이며 실제 관찰 결과가 아니다.

## 시작 전

- [ ] 첫 커플을 P01로 정한다. 연락처나 실제 이름은 기록 파일에 넣지 않는다.
- [ ] 두 사람에게 [참가자 안내](participant-guide.md)를 보여주고, 성인 대상·자발적 참여·둘 다 제출한 뒤 서로의 전체 답변 공개를 각자 확인한다.
- [ ] A는 별도 테스트용 Chrome 프로필, B는 Chrome 시크릿 창을 사용한다. 다른 브라우저 조합도 가능하지만 **탭만 두 개 열거나 시크릿 창만 두 개 여는 방식으로 분리하지 않는다.**
- [ ] 기존 운영자 브라우저의 결과나 쿠키는 삭제하지 않는다. 테스트를 위한 새 프로필/창만 준비한다.
- [ ] A에서 `http://127.0.0.1:3200/`을 연다. 서버가 종료됐다면 저장소에서 `pnpm dev`를 실행한다.
- [ ] 기존 `.local-validation/records.json`이 있으면 유지한다. 없을 때만 `pnpm validation:init`으로 만든다.

## 진행 순서

1. **A 시작:** A에게 랜딩을 보고 스스로 시작하게 한다. 응답 중에는 B와 진행자가 화면을 들여다보거나 선택을 유도하지 않는다.
2. **A 제출·초대:** 본인 결과를 확인한 뒤 초대 링크를 만들고 복사한다.
3. **B 참여:** 복사한 링크를 **같은 컴퓨터의 B 전용 브라우저**에 붙여넣는다. A의 결과 주소 대신 초대 링크를 사용한다. B가 직접 동의하고 응답한다.
4. **함께 비교:** 두 사람 모두 제출하면 전체 비교를 읽게 한다. 진행자는 설명을 보태기 전에 참가자가 결과를 어떻게 이해했는지 묻는다.
5. **무료 대화:** 편한 시작 질문 하나로 대화해보게 한다. 내용은 기록하지 않고, 실제로 대화를 시작했는지만 확인한다. 원치 않으면 건너뛴다.
6. **가격 반응:** 가이드를 무료로 열어주기 전에 예정 가격 3,900원을 보여주고, 지금 선택할 의향을 묻는다.
7. **선택 체험:** 원할 때만 모의 결제로 가이드를 열고 질문·대화 예시·약속 양식을 써보게 한다. 실제 돈은 청구되지 않는다.
8. **마무리:** 도움 없이 이해했는지, 대화에 실제 사용했는지, 구체적인 유용성을 설명했는지와 막힌 부분을 [기록 사용법](recording-guide.md)에 따라 기록한다. 두 사람에게 결과 재접근·함께 삭제되는 범위를 안내한다.

P01의 STARTED/COMPLETED/STOPPED 상태는 실제 진행 시에만 바꾼다. 하지 않은 관찰은 null로 둔다. 테스트가 끝난 뒤 `pnpm validation:report`로 집계한다.

## 다음 커플로 넘어갈 때

- 이전 참가자의 결과를 새 참가자에게 보여주지 않는다. A/B 전용 프로필·시크릿 세션을 모두 종료하고 새 조합으로 준비한다.
- 참가자의 결과를 보관할지는 참가자와 확인한다. 새 커플을 준비하기 위해 이전 결과를 자동으로 삭제하지 않는다.
- P02~P05도 같은 절차를 따른다. 모의 결제를 실제 구매로, 진행자의 도움을 받은 이해를 독립적인 이해로 집계하지 않는다.

휴대전화에는 이 루프백 주소를 공유하지 않는다. 같은 자리에서도 휴대전화로 참여하려면 별도 접속 환경 준비가 필요하다. 첫 테스트는 이 컴퓨터의 두 브라우저에서 진행한다.
