# 참가자 안내 — 우리사이 연구소 첫 사용 테스트

이 안내는 진행자가 참가 동의를 확인할 때 사용합니다. 아직 모집이나 메시지 발송은 진행하지 않았습니다.

## 어떤 테스트인가요?

연인 두 사람이 각자 12개 질문에 답하고, 서로 편한 방식을 비교한 뒤 대화해보는 웹사이트의 사용 테스트입니다. 정답이나 관계 점수는 없습니다. 만 19세 이상 성인 중 두 사람 모두 자발적으로 참여하는 경우를 대상으로 합니다.

완성된 서비스를 구매하는 절차가 아닙니다. 현재 결제는 모의 기능이며 실제 돈이 청구되지 않습니다. 향후 가이드의 예정 가격은 커플당 3,900원이고, 이번 테스트에서는 구매 의향과 실제 결제를 구분합니다.

## 미리 알아주세요

- 제출 전에는 본인의 답변만 볼 수 있습니다. **둘 다 제출하면 서로의 12개 답변 전체와 별명을 볼 수 있습니다.** 이 공개 범위가 편한지 각자 확인해주세요.
- 참여 중 그만두거나, 대화에서 불편한 질문을 건너뛸 수 있습니다. 모든 문항에 답해야 결과가 생성되지만 결과를 만들기 위해 응답을 강요하지 않습니다.
- 진행자에게 답변이나 사적인 대화 내용을 설명할 필요는 없습니다. 화면과 이용 방법에 관한 의견만 부탁드립니다.
- 결과는 현재의 자기보고 응답을 바탕으로 한 대화 참고 콘텐츠입니다. 심리검사·상담·진단·미래 예측을 제공하지 않습니다.
- 녹음·녹화·응답 화면 캡처는 기본적으로 하지 않습니다. 이름이나 연락처 대신 커플 코드로 관찰 결과를 기록합니다.
- 개인 브라우저 쿠키로 접근합니다. 쿠키를 지우거나 다른 브라우저로 옮기면 이어서 접근하기 어려울 수 있습니다.
- 무료 결과 아래 삭제 메뉴는 두 사람의 답변과 결과를 함께 삭제합니다. 상대와 확인한 뒤 이용해주세요.

## 직접 해볼 일

1. 한 사람이 먼저 시작해 평소 더 편한 선택에 답합니다.
2. 본인 결과를 보고 상대에게 초대 링크를 전달합니다.
3. 상대도 자신의 브라우저에서 참여하고 각자 응답합니다.
4. 함께 비교 결과를 읽고 편한 질문 하나로 대화해봅니다. 대화 내용은 진행자에게 알리지 않아도 됩니다.
5. 무료 결과를 써본 뒤, 예정 가격과 가이드의 구성에 대한 생각을 남깁니다.
6. 원하면 모의 구매로 가이드를 열어 질문·예시·약속 양식을 살펴봅니다.

## 마친 뒤 들려주세요

- 무엇을 해야 할지 막막했던 화면이 있었나요?
- 결과를 자신의 말로 설명하면 어떤 의미인가요?
- 실제로 대화를 시작하는 데 사용했나요? 아직 하지 않았다면 그렇게 알려주셔도 좋습니다.
- 어떤 질문이나 예시가 쓸모 있었거나 아쉬웠나요? 사적인 답변 내용은 말하지 않아도 됩니다.
- 무료 결과를 본 시점에 3,900원 가이드를 선택하고 싶었나요? 무료 가이드 체험 뒤 생각이 바뀌었는지도 따로 들려주세요.
